# SQL_Project
Loan Default Risk Analysis – SQL Project

This project focuses on analyzing loan application data to understand approval trends, default risks, borrower behavior, and financial patterns.
Using SQL queries, the project answers 25 practical business questions commonly used in banking, credit risk analysis, and data analytics.

Note: In this dataset,

TARGET = 0 → Loan Approved

TARGET = 1 → Loan Not Approved / Defaulted

# Project Objectives**

Understand the distribution and characteristics of loan applicants

Analyze default behavior across demographics, income groups, and loan types

Calculate approval and rejection rates

Identify high-risk customers

Generate business-ready insights for credit risk teams

# Technologies Used
SQL (MySQL)

Data Cleaning & Transformation

Aggregations, CASE statements, Grouping, Ordering




# Project : Sales Data Analysis
This project focuses on performing detailed sales analytics using SQL queries on a dataset named product_sale.
It covers filtering, grouping, aggregation, window functions, date functions, and trend analysis — making it a complete SQL practice and analysis project.

# Project Overview
The objective of this project is to analyze sales performance across regions, products, customers, and sales representatives.
Using SQL, multiple business questions are solved to derive insights such as:

Best performing products and regions

Sales trends over time

Revenue and profit distribution

Customer behavior (New vs Returning)

Discount impact

Contribution analysis

Ranking-based insights using window functions

The dataset includes fields such as Sales_Rep, Region, Product_Category, Sales_Amount, Unit_Price, Unit_Cost, Payment_Method, Customer_Type, Quantity_Sold, Discount, Sales_Channel, Sale_Date, etc.
